# Project Philosophy

Compact operating rules distilled from [learnings.md](./learnings.md) and [mistakes.md](./mistakes.md). Source links point to the active notes.

- **One spine, thin surfaces.** Shared research/data behavior belongs in AQL/Zopedia/data contracts; Streamlit, API, jobs, and adapters render or trigger it. No sidecar agents or shortcut LLM paths. Refs: [L17](./learnings.md#L17), [L197](./learnings.md#L197), [M59](./mistakes.md#L59), [M144](./mistakes.md#L144).
- **Fix upstream.** Wrong output means inspect the data, service, contract, or materialized artifact first. Product state must be durable, typed, and traceable; UI copy is not a data model. Refs: [L18](./learnings.md#L18), [L19](./learnings.md#L19), [M36](./mistakes.md#L36), [M75](./mistakes.md#L75).
- **Ground before writing.** Preserve rich text, chunks, source refs, and coverage checks before synthesis. Read memory/source refs before citing them; cap confidence or fail closed when evidence is thin. Refs: [L44](./learnings.md#L44), [L148](./learnings.md#L148), [L154](./learnings.md#L154), [M37](./mistakes.md#L37), [M118](./mistakes.md#L118).
- **Use LLMs for narrative and planning; use code for contracts.** Do not hardcode user-facing prose, market intent classifiers, or query-specific branches. Code should enforce schemas, tool access, timeouts, evidence coverage, and audit. Refs: [L65](./learnings.md#L65), [L147](./learnings.md#L147), [M44](./mistakes.md#L44), [M109](./mistakes.md#L109).
- **Agents need coverage, not theater.** More tools or choreography do not fix weak retrieval. Plan evidence slots, preserve the user's wording, seed required context, and use internal evidence before live search when appropriate. Refs: [L53](./learnings.md#L53), [L55](./learnings.md#L55), [L186](./learnings.md#L186), [M98](./mistakes.md#L98), [M110](./mistakes.md#L110).
- **Product screens hide plumbing.** Users see actions, answers, evidence, progress, and clear unavailable states. Admin/job/materialized/runtime language and operational controls belong in Admin, docs, or logs. Refs: [L72](./learnings.md#L72), [L137](./learnings.md#L137), [L182](./learnings.md#L182), [M95](./mistakes.md#L95), [M103](./mistakes.md#L103).
- **Keep render paths cheap and bounded.** Show existing state first. Heavy AQL/LLM/media work runs in scheduled jobs or explicit actions, with per-step timeouts and the same failure contract at every wrapper. Refs: [L101](./learnings.md#L101), [L106](./learnings.md#L106), [M82](./mistakes.md#L82), [M94](./mistakes.md#L94).
- **Make durable changes auditable and reversible.** Chat, memory writes, social state, generated assets, and learning updates need stable anchors, source refs, audit rows, promotion states, and executable rollback where relevant. Refs: [L159](./learnings.md#L159), [L160](./learnings.md#L160), [L171](./learnings.md#L171), [L196](./learnings.md#L196), [M119](./mistakes.md#L119).
- **Verify the live user path.** Test the smallest callable unit, then the exact screen, API, job, deployed env, and runtime identity as applicable. Code exists does not mean the feature is live. Refs: [L37](./learnings.md#L37), [L165](./learnings.md#L165), [L176](./learnings.md#L176), [M18](./mistakes.md#L18), [M142](./mistakes.md#L142).
- **Security and deployment fail closed.** Secrets live in Key Vault, auth/session restore re-checks current status, dev deploys use repo scripts, and prod waits for explicit permission. Runtime env and identity are part of the release. Refs: [L31](./learnings.md#L31), [L155](./learnings.md#L155), [M14](./mistakes.md#L14), [M30](./mistakes.md#L30), [M163](./mistakes.md#L163).
