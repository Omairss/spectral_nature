# Security Review Hub

This folder tracks security reviews, plaintext-secret findings, auth risks, and follow-up actions for this repo.

## Current docs

- `SECURITY_REVIEW_2026-04-11.md`: full repo review covering tracked secrets, auth behavior, local repo inventory, plaintext exposure, and hotlink risk
- `SECURITY_REMEDIATION_2026-04-11.md`: follow-up remediation log covering secret rotation, code hardening, and Azure log-check results

## Rules

- Put dated security reviews here.
- Keep findings tied to exact file paths and line numbers when possible.
- Separate actual secrets from lower-severity infra metadata and external-link risk.
- Record the remediation order, not just the findings.
