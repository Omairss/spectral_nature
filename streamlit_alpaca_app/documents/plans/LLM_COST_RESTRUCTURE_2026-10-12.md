## Objective

Reduce cost per useful investigation while preserving breadth, indirect leads, evidence and timely event discovery. The planning estimate is 49% for the audited workload; this is not an observed saving or a steady-state production forecast. Changes operate in shared AQL/Zopedia and provider/persistence owners.

## Owned contracts

1. Research dossiers own organized findings. Remove the unconditional per-question reinterpretation pass. The dossier chooses additional questions worth acquiring evidence for; the shared agent researches them together and updates the dossier. Existing findings and incomplete leads remain available to the final writer. Durable knowledge authorization stays separate.
2. Persist immutable research artifacts by environment, declared access scope, subject, exact input and inference contract. Reuse completed source-grounded stages and retain prior investigations as dated input for incremental planning. Changed evidence and forced refresh invalidate reuse. Public-company research can enter the existing retained-evidence corpus for all research surfaces; private conversational work is not silently shared.
3. Render stable common evidence before variable instructions. Preserve complete acquired passages and use the existing lossless reference representation. Measure actual cached input rather than claiming a hit from repeated text.
4. Record every provider HTTP attempt, including repair, empty response, embeddings and audio. Keep logical gateway events distinct from billable attempt usage. Preserve environment and causal root/parent identities. Never infer zero cost from missing usage.
5. A shared account circuit opens on a terminal balance failure and checks the free provider balance endpoint for recovery. It prevents repeated rejected requests across jobs without blocking independent data publication or discarding completed research.
6. Thinking effort is an explicit call contract, independent of labels such as formatter. Start with mechanical schema conversion; compare real complete outputs before reducing semantic research or review effort. Consolidate review only when another declared owner reviews the same final artifact; memory-write authorization remains independent.
7. Extend exact content/model/version reuse to graph vectors and narration through the shared persistence boundary. Existing corpus embedding reuse and Trading Agent horizon reuse remain.

### Implemented ownership

- `services/llm_execution.py` owns causal call context, actual provider attempts, account failure recovery, versioned price estimates and completed research checkpoint/replay. `services/llm.py` meters transport attempts rather than logical calls, including retry/repair, embeddings and audio. Unknown usage and unknown prices remain explicit. Reasoning tokens are already part of completion tokens and are not charged twice.
- `services/pipeline_store.py` owns the dedicated provider-attempt ledger and execution-state table. A completed artifact, exact-input replay pointer and latest subject/task pointer commit in one transaction. A forced refresh can supersede a pointer without mutating earlier artifacts. Optional accounting failures do not discard useful research.
- The database schema is shared across tracks: this release adds execution-state and attempt tables without changing production research rows. Research/vector/audio records declare their environment; billing-circuit state identifies the shared provider account. Production application and job images are not updated by this rollout.
- `services/aql/business_model_stack.py` removes the unconditional per-question interpretation pass. The dossier organizes complete evidence and chooses worthwhile follow-up questions. One coordinated investigation answers related questions; a typed delta replaces only explicitly identified findings and preserves the rest. Completed continuations replay without buying the same follow-up again. Subsequent runs can inspect dated prior research and choose zero or more new acquisition questions.
- Public producers explicitly declare `LLM_RESEARCH_ARTIFACT_ACCESS_SCOPE=public_company_research`. Private API and private research workers leave this unset, so their inputs do not silently become shared company checkpoints. Artifacts and vectors include environment identity. The general agent can read declared public research through the existing tool registry.
- `services/llm_context.py`, the company owner and the shared agent preserve complete passages, share exact repeated content by reference, and put stable evidence before changing instructions. Growing tool history uses append-only reference definitions; clocks and changing planner state follow that evidence. JSON schemas follow common user evidence instead of changing the system prefix on every task.
- The shared agent explicitly declares whether it or a downstream owner reviews the final artifact. Acquisition-only company planning can defer review only when it cannot write knowledge. Default answer and memory authorization review remain. Narrow trajectory monitoring uses low effort after a paired live comparison; semantic research and final writing retain thinking. Only literal schema conversion and nested JSON repair disable thinking and bypass the global prose style policy.
- `services/page_agentic_summary.py` lets a single editor return corrected public fields, avoiding review/rewrite/re-review loops. A valid draft survives incomplete review with its actual state. The editor receives the operation's remaining deadline rather than an incidental 60-second default.
- Graph vectors reuse exact description content within the configured embedding space. Narration reuses the immutable audio receipt for identical normalized text, voice, model, format, endpoint and environment. Changed content invalidates these keys.

The source also removes evidence/finding character cuts and categorical status filtering that could erase useful context. New research topics remain available even if they do not match the historical dossier group vocabulary. These are global context-contract corrections, not company-specific rules.
